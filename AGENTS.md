# Project instructions for Lumen

- Prefer GDScript unless the project already uses C#.
- Do not add multiplayer relays, account systems, or analytics SDKs unless the user asks in this chat.
- Do not rewrite files under addons/lumen.
- After editing a scene, keep node names stable. Do not rename roots.
- If a tool fails, report the error instead of retrying the same call more than twice.
